# Epic Arena

Пошаговый RPG Auto-Battler на Angular 22+ (Signals, zoneless, Dark Fantasy UI).

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:4200/`.

## Тесты

```bash
npm test
```

## Возможности

- Команды Альянс / Орда по 3–5 героев (Воин, Маг, Лучник, Жрец)
- Инициатива по Speed, базовая атака + 2 умения на класс
- Броня / MR / крит / уклонение / щит / DoT / Stun / Slow / Taunt
- ИИ по классам, combat log, floating markers
- Плеер: Play / Pause / Step / скорость 0.5×–4×
- i18n RU/EN, тема dark/light, хоткеи

## Хоткеи

| Клавиша | Действие |
|---------|----------|
| Space | Play / Pause |
| N | Step |
| R | Random teams (setup) |
| Enter | Start / Resume |
| Backspace / 0 | Reset |
| T | Theme |
| G | Language |
| H | Help |
| Esc | Close help |

Спецификация продукта: `../docs/`.

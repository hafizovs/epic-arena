# 09 — Acceptance Criteria & Definition of Done

Чеклист приёмки. Генератор после завершения работ **обязан** пройти каждый пункт. Пункт провален → доработать код, не оправдываться.

---

## 9.1 Build & Run

- [ ] `npm install` завершается без ошибок
- [ ] `npm start` / `ng serve` поднимает приложение
- [ ] Консоль браузера без ошибок runtime при старте
- [ ] Нет красных ошибок Angular (NG0xxx) в консоли
- [ ] Zoneless: Play/Pause/Step обновляют UI без Zone.js hacks
- [ ] В зависимостях нет three / ngrx / chart.js / phaser
- [ ] Если Tailwind не подключён — SCSS variables тема работает; если подключён — конфиг полный

---

## 9.2 Конструктор команд

- [ ] На старте есть две команды по умолчанию (минимум 3v3)
- [ ] Можно выбрать класс в каждом слоте (Воин/Маг/Лучник/Жрец)
- [ ] Можно добавить слоты до 5 и убрать до 3 на сторону
- [ ] «Сгенерировать случайные команды» пересобирает обе стороны
- [ ] Во время боя редактирование состава заблокировано
- [ ] Reset возвращает phase в setup и восстанавливает ресурсы текущего roster

---

## 9.3 Плеер симуляции

- [ ] «Запустить бой» стартует автоцикл ходов
- [ ] «Пауза» останавливает автоцикл, состояние сохраняется
- [ ] «Следующий шаг» выполняет ровно один ход/тик
- [ ] Слайдер скорости принимает диапазон 0.5×…4× и меняет задержку
- [ ] Hotkeys Space / N работают согласно документу 01

---

## 9.4 Боевая механика

- [ ] Очередь ходов строится по Speed (инициативе), не случайно
- [ ] У каждого класса есть basic attack + 2 уникальных умения
- [ ] Воин: Провокация (taunt) и Мощный удар реализованы
- [ ] Маг: Огненный шар (AoE) и Ледяная стрела (slow) реализованы
- [ ] Жрец: Исцеление и Щит реализованы
- [ ] Лучник: 2 уникальных умения из Appendix A реализованы
- [ ] Физический урон снижается броней; магический — MR
- [ ] Криты увеличивают урон по critMultiplier и логируются
- [ ] Уклонение даёт полный miss
- [ ] Щит абсорбирует урон до HP
- [ ] Bleed/Poison наносят DoT в начале хода
- [ ] Stun пропускает ход
- [ ] Slow/Haste влияют на инициативу следующей пересборки очереди
- [ ] Бой завершается победой стороны, когда враги мертвы

---

## 9.5 ИИ

- [ ] Жрец хилит союзника с низким HP (< 50%), если есть мана на heal
- [ ] Маг при полной мане предпочитает Огненный шар
- [ ] Воин фокусит врагов с наименьшим HP (или taunt-цель)
- [ ] ИИ не выбирает скиллы дороже текущей маны (fallback basic)
- [ ] Цели под taunt атакуют taunter’а, пока тот жив

---

## 9.6 Арена / визуал

- [ ] Левая команда = Альянс, правая = Орда
- [ ] Карточки показывают HP bar, Mana bar, имя, класс
- [ ] Иконки активных баффов/дебаффов видны на карточке
- [ ] При уроне/хиле/крите появляются animated floating markers
- [ ] Активный герой хода визуально выделен
- [ ] Мёртвые герои визуально отличены
- [ ] Тема Dark Fantasy / Cyberpunk RPG: тёмный дашборд, brand Epic Arena заметен
- [ ] Desktop и mobile layout не ломают арены (usable)

---

## 9.7 Combat Log

- [ ] Каждое действие пишет запись в лог
- [ ] Примерный уровень детализации соответствует брифу (урон, mitigation, эффекты)
- [ ] Цвета: урон красный, хил зелёный, бафф синий (и т.д. по токенам)
- [ ] Автоскролл вниз при новых событиях (если пользователь у низа)
- [ ] `role="log"` / live region присутствует

---

## 9.8 UX расширения

- [ ] i18n RU↔EN переводит UI-строки
- [ ] Theme dark/light переключает панели
- [ ] Help overlay открывается на H и закрывается Esc
- [ ] Hotkeys не срабатывают в input/select

---

## 9.9 Тесты

- [ ] `damage.formulas.spec.ts` проходит
- [ ] `initiative.spec.ts` проходит
- [ ] `effect-engine.spec.ts` проходит
- [ ] AI specs (warrior/mage/priest) проходят
- [ ] `battle-engine.service.spec.ts` проходит
- [ ] `npm test` завершается успешно (или эквивалент CLI)

## 9.10 Качество кода

- [ ] Нет `// TODO`, `// ...`, `// аналогично`, `...existing code...`
- [ ] Нет `*ngIf`, `*ngFor`, `*ngSwitch`
- [ ] Нет BehaviorSubject/Subject для UI/battle state
- [ ] Standalone + Signals + `@if`/`@for` используются
- [ ] Файлы канона брифа существуют:
  - `models/rpg.interfaces.ts`
  - `services/battle-engine.service.ts`
  - `services/hero-factory.service.ts`
  - `components/arena-board/...`
  - `components/combat-log/...`
  - `components/game-director/...`
- [ ] Чеклист [08-file-checklist.md](08-file-checklist.md) выполнен на 100%

---

## 9.11 Definition of Done (финальный вердикт)

Приложение считается готовым **только если** все пункты §9.1–§9.10 отмечены выполненными, `ng serve` показывает играбельный auto-battler, и генератор может кратко описать, как вручную проверить J1–J7 из документа 01.
